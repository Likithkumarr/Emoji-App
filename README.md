## 😀 Emoji App
A simple and interactive Emoji Web Application built using React.js.
This app allows users to explore and interact with emojis in an easy and user‑friendly interface.

## 📊 Project Overview
- Display a collection of emojis in a grid layout
- Click on emojis to interact with them
- Clean and simple user interface
- Responsive design for desktop and mobile devices
- Built entirely with front‑end technologies

## 🛠️ Tools & Technologies
- React.js – component‑based UI
- JavaScript (ES6+)
- HTML5 & CSS3
- React Hooks & State Management

## 📂 Repository Contents
- src/ – React source code
- components/ – reusable UI components
- App.jsx – main application logic
- index.html – application entry point
- README.md – project documentation

## 🚀 How to Run
### Clone the repository
      - git clone https://github.com/Likithkumarr/Emoji-App.git
### Navigate to the project folder
      - cd Emoji-App
### Install dependencies
     - npm install
### Start the development server
     - npm run dev
### Open your browser at
     - http://localhost:5173
